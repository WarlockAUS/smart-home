# Smart Home

A collection of Home Assistant blueprints, automations, and related
projects for my smart home setup.

## Projects

### Battery Level Alert (Blueprint)
Monitors battery-powered sensors and sends escalating notifications
(warning / critical) plus an optional daily digest.
See [`docs/battery_alert.md`](docs/battery_alert.md) for full details
and the one-click import link.
